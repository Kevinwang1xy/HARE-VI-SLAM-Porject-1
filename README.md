# HARE-VI-SLAM-Porject-1
Initial project of VI SLAM integration into UAV: : connecting and integrating SLAM algorithm into Rasberry Pi 5 with RBG Camera


This project will attempt to replicate ORB-SLAM 3 as the main version of VI SLAM in UAV navigation. This project will attempt to set up and run a simple SLAM algorithm on a Rasberry Pi 5 (with AI HAT) module, with a FLIR BFLY-PGE-23S6C-C RBG camera and a LORD 3DM-GX5-25 IMU as main sensors.
